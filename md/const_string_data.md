# Constant String Data

As an example application

```
int main() {

    int result = strlen("msg_const_val");

    return result;
}
```

The constant string "msg_const_val" needs to be output as a labeled define in the .data section:

```
    .data
msg_const_val DB 'msg_const_val', 00h
```

## General idea

A const string used as a parameter to a function call causes the ```type_checking_visitor``` to insert an Expression-AstNode of operator-type AddrOf into the tree.

That way, code is generated which retrieves the constants address (using a LEA instruction) and writes it into the register or stack which functions as storage for the parameter to the function according to the calling convention.

```
; Function Preamble - save space on stack for all local variables - [AsmAstConversionVisitor::visit_tacky_function()]    ; + Updated in AsmAstFixupVisitor::visit_asm_ast_function()
    sub rsp, 8

    ; load address of constant into ecx for the first parameter
    lea rbx,  [msg_const_val] ;     ; lea for GetAddress()
    mov qword ptr [rbp-8], rbx ; lea cannot load into mem, so it loads into reg. This move loads reg into dest mem

    ; FunctionCall - Allocate space for parameters that need to go onto the stack according to the ABI - [AsmAstConversionVisitor::visit_tacky_fun_call_system_v_abi()]    sub rsp, 0
    mov ecx, dword ptr [rbp-8]    ; mov into register fun_call argument 0
    call strlen

    ; return value is in eax
    mov dword ptr [rbp-8], eax    ; mov EAX into TACKY dst variable Variable(userdef_var.1)
    mov eax, dword ptr [rbp-8]    ; Generated by the Return keyword in TackyToIntermediateAsmConversionVisitor
```

## How are constants output into the .data section?

The struct ```AsmAstMasmEmitterVisitor``` has the function ```pub fn visit_data_section()``` which is called in main and which will write the constants into the .data section.

The vector ```data_section``` is not created as a global variable in main. Instead it is implemented as a vector of sub-type ```AsmAstInstruction``` as a member of the ```TackyToIntermediateAsmConversionVisitor``` struct.

```
data_section: Vec<Box<AsmAstInstruction>>,
```

Entries are inserted into the vector inside

```
TackyToIntermediateAsmConversionVisitor::visit_tacky_get_address()
```

and in the match-branch for ValueElement::Constant(const_val)

```
ValueElement::Constant(const_val) => {

    // println!("const_val: '{}'", const_val);

    // add a global const for the data section into the application
    let mut global_constant_instruction = AsmAstInstruction::new();
    global_constant_instruction.instruction_type
        = AsmAstInstructionType::GlobalConstantDeclaration;
    global_constant_instruction.src = AsmAstOperand {
            operand_type: AsmAstOperandType::ImmString(String::from(const_val))
        };
    self.data_section.push(Box::new(global_constant_instruction));

    let symbol_table_entry_option = self.symbol_table.borrow_mut().get(const_val);
    let symbol_table_entry = symbol_table_entry_option.expect(
        format!("No symbol for '{}' found in symbol table!\n", const_val).as_str());
    lea.src = AsmAstOperand { operand_type: AsmAstOperandType::DirectGetAddress(const_val.clone()) };
}
```

The actual iteration over the vector and the printing is done in the ```asm_ast_masm_emitter_visitor``` struct in the ```function pub fn visit_data_section()```.



# Symbol Table Treatment

All relevant locations have been marked with the word: SYMBOL_TABLE_CONST_STRING

It is unclear if the constant needs to go into the symbol table or not.

Currently the constant is inserted into the symbol table in the ```type_checking_visitor``` struct in the match branch for ```AstNodeType::ConstString```

```
AstNodeType::ConstString => {

    let string_val = ast_node.string_val.clone();

    // insert param into the symbol table
    let mut symbol_table_entry: SymbolTableEntry = SymbolTableEntry::new();
    symbol_table_entry.name = string_val.clone();
    symbol_table_entry.initial_name = string_val.clone();
    symbol_table_entry.symbol_table_entry_type = SymbolTableEntryType::Variable;
    symbol_table_entry.data_type = DataType::DataTypeString;
    symbol_table_entry.parameter_count = 0usize;
    symbol_table_entry.has_body = false;
    symbol_table_entry.is_array = false;
    symbol_table_entry.is_pointer = false;
    symbol_table_entry.string_val = string_val.clone();
    let mut symbol_table = self.symbol_table.borrow_mut();
    symbol_table.insert(string_val.clone(), symbol_table_entry);

    return DataType::DataTypeString;
}
```
